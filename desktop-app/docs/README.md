# 文档总览

这个目录用于定义桌面软件 V1 的产品边界、交互结构和后续开发约束。

## 文档列表

- `V1_PRODUCT_SPEC.md`: V1 产品方案，定义目标、范围、流程、验收标准
- `INTERACTION_STRUCTURE.md`: 交互稿结构，定义页面布局、关键操作、状态切换

## 当前产品定位

这个软件不是通用视频编辑器，而是一个面向体操比赛视频处理的高效审片工具。

核心思路：

1. 拖入多个原始比赛视频
2. 调用 AI 检测字幕，生成候选片段
3. 人工快速筛选、预览、微调起止时间
4. 最后只导出保留的片段

## 设计原则

- 优先提升“筛选效率”，而不是堆复杂剪辑功能
- 先做单屏高效率审核，不做完整 NLE（非线性编辑器）
- AI 只负责生成候选，不负责替代人工最终判断
- 导出放在最后一步，避免先生成大量冗余 mp4
