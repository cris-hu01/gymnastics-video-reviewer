# 桌面软件改造目录

这个目录用于承载后续“从脚本走向可交互软件”的全部新内容，与当前根目录下的脚本版流程隔离。

## 目录约定

- `frontend/`: 前端界面，计划使用 React
- `backend/`: 后端能力封装，计划复用并重构现有 Python 检测与导出逻辑
- `docs/`: 产品方案、交互说明、数据结构、开发计划

## 对现有程序的影响

新增这个目录不会影响当前程序运行，原因很简单：

- 现有入口仍然是根目录下的 `run.sh`
- 现有 Python 脚本仍然是 `ocr_ai_detector.py` 和 `clip_athletes.py`
- 当前脚本只处理根目录中的视频文件，不会主动扫描这个新目录

注意：

- 之后如果把视频放进 `desktop-app/` 里，旧脚本不会自动处理它们
- 后续软件化改造应尽量调用根目录脚本重构后的模块，而不是直接依赖 shell 脚本

## 前端技术方向

支持 React 架构，而且这对你用 Google AI Studio 做前端设计是合适的。

推荐方向：

1. 前端：React
2. 桌面壳：优先考虑 Electron；如果后面追求更轻量，再评估 Tauri
3. 后端：Python
4. 视频处理：ffmpeg / ffprobe

这么选的原因：

- 你现有核心能力已经是 Python，复用成本最低
- React 更方便让外部设计工具先产出界面原型
- 后面可以先做界面和交互，再把 Python 能力接进去

## 建议的整体架构

- React 负责：
  - 拖拽导入
  - 任务列表
  - 候选片段列表
  - 筛选
  - 预览与裁剪交互
- Python 负责：
  - 抽帧
  - AI 检测
  - 候选片段生成
  - 最终导出
- 桌面壳负责：
  - 本地文件访问
  - 调用 Python 进程
  - 管理任务状态
